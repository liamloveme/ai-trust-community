# AI交易守望站 V3.2 v1.1.0

本版在 v1.0.1 修复版基础上增加置顶与页脚联系方式管理，保留原有社区、审核、证据保护和可选自建翻译功能。代码继续使用 MIT 许可。

## 新增功能

- 超级管理员可独立设置社区首页置顶；管理员和普通会员无此权限。
- 超级管理员及管理员可设置首页之外帖子列表的板块置顶，普通会员无权操作。首页与板块开关互不影响；搜索和我的帖子保持原排序。下架、驳回清除置顶。
- 仅超级管理员可配置页脚联系方式：总开关、逐项开关、最多4种不同类型（含 QQ、Telegram、X、TikTok 等）。关闭后公开页为空，公开接口不返回后台保留的号码。
- 后端鉴权、事务审计、配置签名与并发版本检查；联系内容作为纯文本显示。

## 从 v1.0.1 升级

已有站点先备份数据库、上传和表情卷并验证恢复，停止应用写入，执行一次 `database/migrations/007-v3.2-pins.sql`，再启动新版。新安装使用最新 `database/schema.sql`，不再运行007。不要覆盖旧库或删除数据卷；完整命令见 [部署提示词](../Codex一键部署提示词.md)。

## 验证与范围
