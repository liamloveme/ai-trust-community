# 上线与开源验收清单

- [ ] npm ci 使用交付锁文件；生产依赖审计与许可核查完成。
- [ ] production/HTTPS/Turnstile/HMAC/DB/Redis/SMTP 配置正确且无默认密码。
- [ ] 反代真实IP可信且多人限流独立；公网仅开放所需代理入口。
- [ ] MySQL初始化或旧库备份更新完成；两个上传卷可写且恢复演练通过。
- [ ] 验证码失败后可重试；登录、找回、修改密码在真实环境通过。
- [ ] 单条/批量角色隔离、101条400、混合结果、审计失败回滚通过。
- [ ] 私密证据隔离、评论审核上下文、下架媒体失效、详情返回来源通过。
- [ ] API时间为UTC，健康依赖故障返回503，存活检查独立。
- [ ] 启用翻译时模型能力、语言对、缓存、队列、重启、长帖实测通过。
- [ ] 数百活跃会话和翻译并发压测达到预定延迟/错误率，资源预警已配置。
- [ ] 发布资料不含生产密钥/用户资料，备份恢复和回滚文档齐全。

本地测试通过不自动勾选生产环境项目。
